# OceanWatch AI — REPRODUCIBLE DEMO SPEC

## GOAL

Create a single reliable demo scenario for judges.

The demo must work without inaccessible Indian government infrastructure.

## DEMO SCENARIO

Region:
Gulf of Mexico (as defined by the project report)

Data:
- a known/demo Sentinel-1 scene or prepared scene
- MarineCadastre AIS
- cached ERA5
- cached CMEMS/HYCOM

Models:
- actual trained Attention U-Net checkpoint once training succeeds
- actual YOLOv8 checkpoint once training succeeds
- actual Isolation Forest fit

Algorithms:
- actual CFAR
- actual GLCM
- actual geometry
- actual OpenDrift
- actual matching
- actual 7-factor score

## DEMO SCRIPT

1. Open Dashboard.
2. Select Spill Incident.
3. Open incident investigation.
4. Show SAR scene and detection overlay.
5. Show confidence and geometry.
6. Start backward drift replay.
7. Show origin probability heat map.
8. Show forward forecast.
9. Show vessel tracks.
10. Show dark-vessel comparison where available.
11. Select top suspect.
12. Expand 7-factor breakdown.
13. Explain calibrated AIS-gap contribution.
14. Generate evidence PDF.
15. Open report preview.

## NO-FAKE RULE

Before real model training/validation exists:
- demo placeholders must be explicitly labeled "demo/simulated"
- never show fabricated values as measured model performance
- separate demo seed records from actual inference artifacts

## FALLBACK

If full-resolution inference cannot run live during a presentation:
- prepare precomputed artifacts generated by the real pipeline
- replay the saved job results through the same UI/API
- show that the stored results came from an actual pipeline run

The UI should still demonstrate the complete workflow.
